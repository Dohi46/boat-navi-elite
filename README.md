# BOAT NEXUS

ボートレースの当日情報・参考予想・買い目・結果検証を表示する開発中のWebサイト。

- サイト: https://dohi46.github.io/boat-navi-elite/
- 一般利用向けの品質目標日: **2026-12-15**（達成を保証する日付ではありません）
- 公開判定: [28日間の公開チェックリスト](docs/LAUNCH_28_DAY_GATE.md)

## 主な構成

- `index.html` / `app.js`: 当日の開催情報、出走情報、参考予想、AI LABなどの画面
- `compare.html`: 予想の比較・検証画面
- `odds-free.html`: オッズを使わない試験AIの事前選択・見送り検証
- `data/auto/YYYY-MM-DD.json`: 現行AIの保存済み予想と、取得済みの結果
- `data/shadow/YYYY-MM-DD.json`: 試験AIの締切前ロック済み予想。旧形式と事前選択形式は区別して評価
- `tools/`: 予想収集、結果照合、試験予想、品質監査など
- `.github/workflows/`: 定時収集、結果照合、品質監査の自動処理
- `manifest.webmanifest` / `sw.js`: PWA向けの設定

## 現在の運用

1. `daily-predictions.yml` が日本時間07:15を目安に当日の予想を収集。
2. 同じワークフロー内で、条件を満たす試験AIの予想と選択・見送りを**締切前のみ**保存。
3. `settle-predictions.yml` が30分ごとに結果照合などを試行。
4. `audit_prediction_health.cjs` と運用監視で欠損・時刻矛盾・未確定結果を点検。

GitHub Actionsのスケジュールには遅延・不実行の可能性があります。予想データ、結果、試験AIの事前登録は日によって欠ける場合があります。旧形式の試験予想を後から「選択・見送り」に分類しません。

## 予想の位置づけ

表示する買い目・参考スコアは研究・情報提供目的で、的中や利益を保証しません。試験AIの順位スコアは校正済みの的中確率や期待値ではありません。予想の的中率・回収率は対象期間・集計条件・未確定データを区別して確認してください。

## データと注意事項

- 主な情報源: [Boatrace Open API（非公式）](https://github.com/boatraceopenapi/api)
- データの欠損・遅延・仕様変更の可能性があります。購入判断の前に公式発表を確認してください。
- BOAT NEXUSはBOAT RACE公式とは無関係です。
- 外部データの利用条件や表示内容の最終確認は一般公開前の必須作業です。

## 開発優先順位

最優先はデータの正確さ、締切前保存、結果照合、スマホ操作性、障害の検知です。有料会員・決済・高度な新規AI機能は一般公開後の検討事項です。

詳しくは [公開チェックリスト](docs/LAUNCH_28_DAY_GATE.md) と [デプロイ手順](DEPLOY.md) を参照してください。
